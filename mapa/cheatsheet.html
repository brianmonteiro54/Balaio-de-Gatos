04 10 pegadinhas que derrubam todo mundo

01RAG ≠ Fine-tuning. Dados que mudam → RAG. Estilo/tom → FT.
02Fine-tuning ≠ Continued Pre-training. Rotulado/pouco → FT. Não-rotulado/muito → CPT.
03Clarify ≠ Model Monitor. Detectar bias → Clarify. Drift em produção → Monitor.
04Q Business ≠ Q Developer. Docs da empresa → Business. Código na IDE → Developer.
05Lex ≠ Bedrock. Interface de chat → Lex. Inteligência → Bedrock. Combinam.
06Temperature alta ≠ resposta melhor. Alta = aleatória. Factual = baixa.
07Alucinação se "mitiga", não se "elimina". RAG + revisão + validação. Resposta com "elimina 100%" → errada.
08Precision ≠ Recall. Falso positivo dói → Precision. Falso negativo dói → Recall.
09Guardrails ≠ IAM. Filtra conteúdo → Guardrails. Controla acesso → IAM.
10"Treinar FM do zero" quase nunca é a resposta. Adapta um pronto (RAG/FT).
